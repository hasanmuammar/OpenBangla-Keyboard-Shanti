Shanti Keyboard is an OpenSource, Unicode compliant Bengali Input Method for GNU/Linux systems. It's a full fledged Bengali input method with typing automation tools, includes many famous typing methods such as Avro Phonetic, Probhat, Munir Optima, National (Jatiya) etc.

Shanti Keyboard is a fork of OpenBangla Keyboard. Most of the features of Avro Keyboard are present in Shanti Keyboard. So Avro Keyboard users will feel at home with Shanti Keyboard in Linux.
